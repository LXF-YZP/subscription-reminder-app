# 申购提醒

macOS 13 及以上的原生菜单栏应用。每天北京时间 **09:30 和 14:30** 查询当天可申购的新股、可转债，并发送系统通知。

1.5.1 版增加菜单中指数点位、涨跌幅的红涨绿跌显示；1.5.0 版为股票详情增加分时、日/周/月蜡烛K线、成交量与悬停读数，支持场内 ETF / LOF 自选；新增基金名称/代码搜索、历史净值走势图和逐日净值详情。保留原日历图标、申购与缴款提醒、标记、自选条件、交易日历及备份功能。

## 使用

安装后，右上方菜单栏保留原有日历图标，右侧显示 **「申购提醒①」**，带圈数字为当天尚未标记已申购的新股和可转债数量；全部标记已申购或当天无项目时，隐藏带圈数字，仅显示图标和「申购提醒」。文字和带圈数字统一使用系统菜单栏字体与字号。第一次运行时，在系统弹窗里选择 **「允许」**，以便收到提醒。系统设置 → 通知 → 申购提醒，可将提示样式设为「提醒」，让消息保留到手动关闭；专注模式可能会静音通知。

- 鼠标悬停在菜单栏的「申购提醒」上，可查看日期、每日提醒时间、更新时间和待申购数量。
- 「今日申购」「自选股」「今日缴款」「今日上市」在主菜单各占一行，和「后续申购日历」一样向右展开详情。展开申购项目可查看发行价、申购日期、市场和申购代码，支持复制代码；点击「今日上市」里的新股或可转债会直接打开对应证券行情详情。
- 在上午、下午分别提醒一次；同一时段重复检查和重启不重复发送。
- 晚开机或睡眠唤醒后，在 09:30–14:29 补上午提醒，在 14:30–14:59 补下午提醒；15:00 后只更新列表。
- 默认当天无申购不弹消息；可在菜单「设置」里开启无申购通知。
- 周末和已确认的交易所法定休市日不发送定时通知、不自动拉取行情，行政调休周六日仍按休市处理。内置2026年上交所年度休市表，启动及每日后台联网更新并缓存；失败保留已确认日历。未知年份暂按周末规则，悬浮提示和「设置 → 交易日历」明确显示“当年日历未确认”，可手动更新并查看官方来源。新股日历在非交易日仍按小时更新，便于查看后续安排。
- 申购项目菜单中可选择「标记已申购」，标记后停止该项目的申购提醒，并立即从菜单栏数量中扣除；取消标记时恢复计数。已标记项目仍保留在菜单中，方便查看。设置里的「缴款提醒仅针对已申购项目」和「上市提醒仅针对已申购项目」默认关闭。
- 每天 09:30 和 14:30 检查中签缴款与上市项目；北交所新股在申购时预缴资金，不提醒中签缴款。菜单显示「今日缴款」和「今日上市」，点击通知可查看三类今日事项。缴款提醒只是公开日历提示，无法查询个人中签结果；如已中签，请在同花顺核实并按时备足资金。
- 菜单「后续申购日历」展示已经公布的未来项目。
- 「设置 → 打开同花顺」先查找本机应用，也可通过「设置 → 选择同花顺客户端」指定位置。也可以在手机同花顺的「交易 → 新股申购」中自行申请。「退出申购提醒」也位于「设置」子菜单底部。
- 行情详情中点击「加自选」即可保存自选股票；行情窗口顶部会显示自选股及最新涨跌幅，点击可再次打开详情。自选列表保存在 `~/Library/Application Support/SubscriptionReminder/market-preferences.json`。
- 菜单栏「自选股」右侧子菜单中点击「搜索添加股票或场内基金…」，输入股票名称或代码（例如「贵州茅台」「600519」），在结果右侧点击「添加」。支持沪、深、京 A 股、场内 ETF / LOF 及名称部分匹配，可连续添加多只；已加入的结果显示「已添加」，不会重复保存。搜索会排除指数、场外普通基金、港股等其他证券；无网络时仍可搜索本机已缓存的股票。
- 「自选股」子菜单显示名称、代码、现价、涨跌幅和行情时间；涨幅百分比用红色，跌幅百分比用绿色，持平或暂无数据使用默认文字颜色。点击直接打开个股详情；在详情中再次点击「已自选」可移除。自选股不局限于三个指数成分，名称和行情独立保存，重启后保留。行情刷新失败时保留旧数据，尚未获取的价格与涨跌幅显示「—」。
- 申购清单来自公开日历，不判断个人账户的交易权限、市值额度或是否已完成申购；请在同花顺中确认。
- 包含沪深北新股和公开网上申购可转债。北交所新股按相应规则预缴申购资金。

## 条件提醒、中签管理与备份

- **自选股 → 条件提醒…**（设置中也有入口）：选择已有自选股，添加“价格达到或超过”“价格达到或低于”“当日涨幅达到”“当日跌幅达到”条件，可关闭、重新开启或删除。跌幅输入正数，例如3表示跌至−3%。条件满足即提醒，添加时已满足也会触发；采用交易时段每5分钟刷新取得的行情，查询失败按既有间隔重试，不是逐笔盯盘。超过6分钟或旧日行情不触发，午休和休市不触发。每条规则每天一次，重启或开关同一规则不会重置当天记录；点击通知直接打开该股详情。删除自选股会同步删除它的规则，默认没有任何股价条件。
- **申购项目右侧菜单**或**设置 → 申购记录与中签管理**：在券商确认后手动标记“已中签”“已缴款”。中签自动包含已申购；缴款自动包含中签；取消中签会清除缴款，取消已申购会同时清除两种状态。项目退出最近45天的在线日历后，已标记项目的资料仍保留，管理菜单展示最近120条记录。北交所不提供中签缴款标记和提醒。
- 已缴款项目停止09:30、14:30的缴款提醒。**已中签且当天尚未缴款**的项目在14:45、15:30各增加一次提醒；晚开机可在对应时段内补发，16:00后不再补发。菜单显示距16:00的参考时间，实际缴款截止时间以券商为准。本工具不登录证券账户，也无法自动查询个人中签或缴款结果。
- **设置 → 行情异常及恢复通知**默认开启：交易时段连续完整刷新失败3次，或任一范围的指数、榜单或成分股整体行情落后15分钟时通知；同一异常只通知一次。后台检查不重复累计失败次数，午休不累计延迟，非交易日及收盘后不报警。取得完整且时间恢复的数据后，若此前已提交异常通知，再发一次恢复通知。监测状态在设置和悬浮提示里显示，可关闭通知。
- **设置 → 导出设置与自选股… / 从备份恢复…**：JSON备份包含自选、条件规则、三种标记、已标记项目资料和提醒偏好。导入替换这些个人设置；保留本机同花顺路径、登录启动配置、在线日历、现有行情及通知去重。恢复前先自动备份当前设置到运行数据目录的 `Backups/`；拒绝损坏、超大和不一致的文件，中途写失败回滚已写入的文件。

## 行情与排行榜

点击菜单栏 **「申购提醒 → 行情与排行榜…」**，或直接点击菜单中的任一指数，即可打开行情窗口。

- 顶部展示上证指数、深证成指和沪深300的点位、涨跌幅及各自行情时间；点击卡片切换统计范围。指数行情独立保存，成分股查询失败也能更新已成功获取的指数；下方榜单显示自己的行情时间，旧榜单不会被标成最新时间。
- 菜单中的三个指数，点位与涨跌幅按当日涨跌幅着色：上涨红色、下跌绿色；持平或缺少涨跌幅时使用默认颜色。指数名称和缓存提示保持默认文字颜色。
- 每个范围同时展示涨幅前十、跌幅前十、资金流入前十、资金流出前十。
- 范围采用新浪财经对应指数的成分列表，先核对接口声明的总数，再批量查询全部成分行情。深证成指为500只、沪深300为300只；上证范围为该指数成分中的 A 股，不包含以不同币种交易的 B 股。
- 资金按东方财富的**当日主力净流入额（元）**排序；正值进入流入榜，负值进入流出榜。不是成交额、资金总流入或北向资金。界面金额按万、亿换算。
- 点击股票行，可查看现价、涨跌额、涨跌幅、OHLC、成交量和成交额、换手率、量比、总/流通市值、市盈率（动态）、市净率、主力净流入，以及分时走势、最近120根日/周/月蜡烛K线和成交量；支持复制股票代码、打开同花顺和东方财富详情。
- 个股详情使用独立窗口，菜单中的自选股可直接打开，无需先加载完整排行榜。先展示最近已知行情并标注时间，后台分别加载详情与所选周期图表；网络慢或失败时仍可立即关闭。关闭按钮、Esc 和标题栏关闭均取消当前请求，快速切换股票、同一股票重开时会丢弃旧请求的响应。本次运行中保留最近24只股票的详情，以及最多96组证券/周期图表缓存，失败时保留缓存并显示错误，重启后仍可从原有自选行情缓存起步。
- 榜单按北京时间的日期边界直接筛选行情，图表日期在加载时一次转换，蜡烛图使用轻量 Canvas 绘制，避免每次界面更新重复执行大量日期格式化；正式构建启用编译优化。
- 每个榜单标题右侧提供「复制」按钮，复制内容包含指数、榜单类型、数据时间、数据口径、排名、名称、代码和数值，方便粘贴到笔记或消息中。
- 缺失数值用「—」显示。零涨跌/零净额不进入对应方向榜，少于十只按实际数量展示。停牌导致行情日期落后的股票不参与该交易日排名；可用数量显示在每榜底部。
- 若某个范围在备用入口与小批补查后仍缺少行情，保留其上次完整快照并标注失败、缺失数量与原因，不发布不完整的前十榜；其他完整范围照常更新。同日行情落后超过6分钟时提示时间落后，午休以11:30、收盘后以15:00为准，避免正常休市误报。新股日历、行情、个股详情与日线分别处理错误。
- 周末、节假日或当日尚未开盘时，展示上游提供的最近交易日行情，明确显示日期；这些不是今日新成交。

行情在启动时优先读取最近的完整缓存。交易日09:00–15:00每5分钟刷新，失败时1分钟后重试；09:00前每小时刷新；10点后推测休市时每小时探测。15:00后，三个指数都取得当天收盘时间的行情、且各范围成分数据完整时，停止自动刷新；否则每15分钟重试，推测休市则每小时探测。上午缓存、单个指数成功或旧日缓存均不能当作当天完整收盘结果。打开行情窗口会按相同间隔检查是否到期，已到期时立即刷新；周末与已确认休市日不自动拉取，手动刷新可随时触发。菜单「立即刷新」同时刷新申购与行情。实际数据时间以界面标注为准，免费公开接口可能有延迟或限流。

行情优先使用东方财富 `clist/get`，以 `fs=i:市场.代码` 筛选指定证券，备用为 `ulist/get`，两入口同属一个数据源。批量请求最多10路并发，第一轮100只一批（主入口每页上限为100只），显式设置页码、页大小和数组格式；校验响应条数、重复与证券代码，不依赖返回顺序。只对缺失证券再用20只小批补查一次；单次网络请求失败最多重试一次。整个行情流程限制28秒，超时取消在途请求，并返回已成功的指数和完整范围。首次行情查询、失败及恢复成功写入运行记录，包含指数与榜单各自时间及具体入口失败原因；连续正常刷新不重复记录同一状态。

## 股票图表与基金净值

- 打开任一股票详情，在指标下方切换 **分时 / 日K / 周K / 月K**。K线展示开、高、低、收，下方成交量单位为手；红涨绿跌，悬停查看具体数值。分时压缩午休空档，使用上游实际交易日期，虚线为昨收（接口有提供时）。K线最多展示最近120根，最新一根在当前周期结束前仍会变化。
- 图表优先腾讯财经，失败使用东方财富备用入口；按实际响应标注前复权或不复权。每次图表查询最多18秒，详情请求与图表请求独立。切换股票或周期时先展示匹配缓存，失败保留对应缓存；关闭取消请求、丢弃迟到响应，关闭期间不发布状态。只有详情窗口可见且未最小化、处于交易时段时，每60秒刷新图表和报价，午休、收盘、休市暂停。网络延迟以图表/报价各自标注的时间为准。
- 在 **自选股 → 搜索添加股票或场内基金…** 中搜索并添加 ETF / LOF（如510300），点击自选条目查看实际成交价、分时与K线。场内基金详情的 **查看基金净值** 按钮按基金代码打开净值查询；场内成交价格与已公布净值分别展示，不能混用。
- 在 **自选股 → 基金走势与净值…**，或股票详情底部同名按钮，输入普通基金的名称或代码，点击搜索结果查看。基金代码使用独立空间，不会把基金000001当作股票000001。普通基金不加入股票自选及股票价格条件提醒。
- 基金页展示最新已公布单位净值、日增长率、近1月/近3月/近1年/全部历史净值走势，以及按日倒序的单位净值、累计净值、日增长率；「显示更早净值」逐批展开详情。范围以最新净值日期为终点，全部历史曲线超过700点时抽样绘制并保留末点，逐日表保留上游全部有效记录。历史单位净值曲线不代表含分红再投资的收益率，缺少累计净值时显示「—」。重新打开或点击「刷新净值」拉取最新公布数据，失败保留本次运行的基金缓存（最多12只）。
- **普通基金正式净值通常每日公布一次。当前公开盘中估算接口未提供有效数据，普通基金页明确显示暂无盘中估算，不能将历史净值称作实时走势。** 需要盘中交易走势可查看场内 ETF / LOF。货币基金的万份收益及七日年化口径暂未支持，搜索中排除货币基金。
- 基金数据来自天天基金（东方财富），只读取代码及净值数组，不执行接口中的 JavaScript。股票与基金图表均只供查看，申购/交易继续在同花顺完成。

## 自动运行与数据

安装脚本会设置登录后自动启动。电脑需要已登录并联网；关机或持续睡眠时不能弹出提醒，唤醒后在上述时段补查。

申购日历在交易日08:00–16:00每5分钟更新一次，其余时间及休市日每小时更新一次；两次提醒时刻会额外查询。两个数据接口并行请求，每个入口有超时限制并最多尝试两个入口。部分失败会明确标记，不以失败结果推断当天无申购。

提醒时查询失败，优先使用当天早些时候成功取得的同类日历；昨日缓存只供查看，不用于确认今日提醒。只要当天有可用结果，就按已知项目提醒并继续重试；当天完全没有可用结果时才发送「查询失败」通知。最新成功返回的空结果会覆盖旧结果，只有两类日历都确认无申购才生成空提醒。

- 数据源：东方财富公开数据接口（新股 `RPTA_APP_IPOAPPLY`、可转债 `RPT_BOND_CB_LIST`）。两个入口同属东方财富，无法替代独立数据源核验。
- 可转债使用 `CORRECODE`（公众申购代码），不会误用证券代码或原股东配债代码；保留代码前导零。
- 日历覆盖最近45天及已公布的未来申购。沪深新股缴款日取 `BALLOT_PAY_DATE`，上市日取 `LISTING_DATE`（缺失时回退 `SELECT_LISTING_DATE`）；转债分别取 `BOND_START_DATE`、`LISTING_DATE`。无效或未公布日期不生成对应提醒，公开日期仍可能调整。
- 缓存、设置与提醒记录：`~/Library/Application Support/SubscriptionReminder/state.json`
- 交易日历缓存：同目录 `trading-calendar.json`；官方来源：https://www.sse.com.cn/disclosure/dealinstruc/closed/
- 自动恢复前备份：同目录 `Backups/`
- 行情缓存：同目录 `market-cache.json`（独立保存，不更改申购记录与通知去重）
- 独立指数缓存：同目录 `index-quotes.json`，与完整榜单缓存各自保留真实行情时间。
- 自选名称与独立行情缓存：同目录 `favorite-quotes.json`；自选代码列表仍使用原有 `market-preferences.json`，兼容已有自选。
- 运行记录：同目录 `activity.log`；超过大小上限时滚动保留为 `activity.1.log`；时间为北京时间并带 `+08:00`。启动输出和错误：`launch.out.log`、`launch.err.log`
- 成功查询仅在启动后首次成功、结果内容变化或从失败恢复时记录，失败每次记录。`activity.log` 上限为512,000字节，轮换时保留一份旧日志。
- 每次启动记录版本及系统实际通知授权状态、提醒样式、声音状态；运行中每20秒、唤醒及打开菜单时检查状态，变化后再记一行。无权限而未发送的同一时段同一事项只记一次，授权后仍可在提醒时段内补发。
- 登录启动配置：`~/Library/LaunchAgents/local.yuezhiping.subscription-reminder.plist`
- 应用：`~/Applications/申购提醒.app`

## 构建与检查

使用系统 Swift 编译器，不需要 Python 依赖、行情账户或 API 密钥。

```bash
./build.sh
./test.sh
./install.sh
```

重新安装会重启正在运行的申购提醒，保留已有设置、自选股和提醒去重记录。菜单重新开启「登录后自动启动」时也会设置与安装脚本一致的启动日志路径。

`test.sh` 包含申购与提醒、榜单日期边界、批量行情入口切换、缺失补查、独立指数与榜单时间、自选保存、详情生命周期、交易日历、条件阈值与去重、中签缴款联动、行情异常、备份恢复及中途失败回滚、菜单与条件窗口检查，以及K线字段、分时日期与午休、基金代码隔离和净值口径、图表/基金切换与关闭取消检查；网络回归使用本地模拟响应，详情测试用可控的未完成请求验证关闭、快速切换、同股重开、缓存与失败回退，不依赖在线行情，也不改动用户运行数据。

实时接口验证，不发送通知、不写运行数据：

```bash
"$HOME/Applications/申购提醒.app/Contents/MacOS/SubscriptionReminder" --check
```

实时行情与榜单完整性验证（JSON含各指数样本数、失败代码、耗时和四个榜单；不写缓存）：

```bash
"$HOME/Applications/申购提醒.app/Contents/MacOS/SubscriptionReminder" --market-check
"$HOME/Applications/申购提醒.app/Contents/MacOS/SubscriptionReminder" --stock-check 1.600519
```

`--stock-check` 的市场前缀为 `1.` 沪市、`0.` 深市或北交所，返回详情及日线条数；股票代码保留前导零。`--show-market` 可以直接打开现有应用的行情窗口。

检查系统通知权限（0=尚未询问、1=已拒绝、2=已允许）：

```bash
"$HOME/Applications/申购提醒.app/Contents/MacOS/SubscriptionReminder" --notification-status
```
